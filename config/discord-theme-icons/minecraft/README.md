# Minecraft Discord icons

The `dark/`, `light/` and `accent/` folders are an unmodified mirror of
[vyfor/icons](https://github.com/vyfor/icons/tree/4b7994fb86cd172b6d455c93f0c1748f86b943f0/icons/minecraft),
snapshot `4b7994fb86cd172b6d455c93f0c1748f86b943f0` (432 PNG files).
Cord uses raw HTTPS URLs from this repository so the upstream asset host is not
needed at runtime. Publish these files to `KristanLaimon/nvim-config` on `main`
before running `:CordReload`.

The Minecraft theme is based on [FuncFusion's Datapack Icons](https://github.com/FuncFusion/mc-dp-icons),
licensed under MIT. Its original copyright notice and license are preserved in
[LICENSE](LICENSE). Cord's modified assets are credited to [@vyfor](https://github.com/vyfor).
Some icons are complemented by the upstream default theme and retain their own
licenses: the upstream attribution catalog is preserved verbatim in
[ATTRIBUTION.md](ATTRIBUTION.md), with its full license texts in [licenses/](licenses/).

`fox-custom/` contains Kristan's separate custom artwork. It is not part of the
upstream Minecraft theme and is not covered by the upstream licensing notices.
